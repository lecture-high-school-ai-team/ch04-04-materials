# まついわ観光案内で課題解決を体験する

観光案内サイトを使い、改善したい点を見つけ、AIに希望を伝えて直し、結果を確かめます。施設・口コミ・観光パスは教材用の架空データです。

## 教材をダウンロードする

1. このリポジトリの上部にある「Code」→「Download ZIP」で、教材を保存してください。
2. 保存したZIPは、そのまま読み込みに使うため残してください。
3. 配布ページのファイル一覧で「演習ノートブック」を選び、「Download raw file」で保存して開いてください。
   - [PyHiroba](https://pyhiroba.weblab.t.u-tokyo.ac.jp/nb/)では、Notebookファイルをインポートしてください。
   - [Colab](https://colab.research.google.com/)では、「ファイル」→「ノートブックをアップロード」から選んでください。
4. 「教材データの読み込み」を開き、準備・読込セルを1回実行して、最初に保存したZIPを選んでください。コードは初期状態で隠れています。
5. 「教材データを読み込みました」と表示されたら、「サンプルサイトの確認」へ進んでください。

「サンプルケース」のNotebookは、改善前のサイトだけを試す場合に使います。演習Notebookと同時に開く必要はありません。

## 課題の選び方

A〜Fから1つ選んで取り組みます。1つ終えたら振り返りへ進みます。2つ目は発展課題です。余力があれば別の課題を選んでください。

## 入っているもの

| 場所 | 内容 |
| --- | --- |
| 演習ノートブック | 手順・スライド・参考プロンプト・記入欄 |
| サンプルケースNotebook | 改善前のサイトを試すためのNotebook |
| `data/` | 8施設・367件の口コミ・4枚の観光パス・写真の数値・学習済み単語ベクトル |
| `images/` | 写真を見分ける活動で使う2枚の画像 |
| `src/` | サイトのプログラムと写真入力用HTML |

スライド画像は演習Notebookに入っています。写真を見分ける活動は、同梱画像だけでも進められます。自分の写真を試す場合だけ、展開した `src/photo_input.html` をパソコンのブラウザで開いてください。

## うまく読み込めない場合

- ZIPは展開したフォルダではなく、拡張子が `.zip` のファイルを選んでください。
- この教材のZIPを1つだけ選んでください。別の教材や、複数の教材をまとめたZIPは使いません。
- 再起動後は、準備・読込セル（ZIPを選択）→サンプルサイトの最初のセルの順に実行してください。
- ページを開けない場合は先生に知らせてください。

教材データの読み込みや、同梱ベクトルを使う検索には外部APIへの接続は不要です。生成AIへの相談と、Colabの初回準備にはインターネット接続が必要です。

## 一覧の表示件数

データ一覧は初期状態で先頭5件です。該当コードセルの `表示件数 = 5` を `10` などの件数、または `"all"` に変えて再実行できます。表示件数だけが変わり、教材データや集計対象は減りません。配布ページの最新のZIPを使ってください。

ZIPを展開すると中のファイルを確認できますが、教材データの読み込みに展開は不要です。
